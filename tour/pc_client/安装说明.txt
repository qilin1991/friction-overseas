杭州亲子·活动汇 —— 电脑端公众号采集（搜狗低频）

一、这是做什么的
  用你家电脑（杭州家宽 IP，最不容易被搜狗拦）去"搜狗微信"搜索杭州各地亲子/活动，
  把结果推送到 VPS 的活动站。VPS 负责政府门户抓取和网站展示，你电脑只负责公众号这块。

二、装 Python（只需一次）
  1. 打开 https://www.python.org/downloads/ 下载 Python 3
  2. 安装第一步一定勾选 "Add python.exe to PATH"
  3. 装完关掉所有命令行窗口

三、运行
  双击  start_wechat_push.bat
  - 首次会自动安装依赖 requests
  - 然后自动循环：跑一轮（约 130 个搜索，25 分钟左右）→ 休息 50 分钟 → 再跑
  - 黑窗口保持开着即可，关闭即停止

四、开机自启（可选）
  按 Win+R，输入  shell:startup  回车，把本文件夹里的 start_wechat_push.bat
  的"快捷方式"拖进去。以后开机自动在后台跑。
  （想要不弹窗口：右键 bat → 属性 → 运行方式选"最小化"）

五、看结果
  打开 http://146.56.250.224/tour/  账号 qilin  密码 0805
  采集日志在：本文件夹的 push_wechat.log

六、常见问题
  - 提示"未检测到 Python"：重装 Python 并勾 Add to PATH
  - 日志里大量 [验证码]：说明这台 IP 被搜狗临时限流，等 1-2 小时会自动恢复；
    也可以在 push_wechat.py 顶部把 --delay 调大（如 20）来降低频率
  - 想改 VPS 地址/口令：编辑 push_wechat.py 顶部的 VPS_BASE / AUTH / TOKEN

七、安全提示
  走的是 HTTP + 基础认证，仅适合自用。请勿把本文件夹（含口令）发给他人。
